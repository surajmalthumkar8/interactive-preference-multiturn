# Per-Task Observation Worksheet

Copy this per task. The point is to separate visual notes from behavioral notes **while
inspecting**, so the three reasons write themselves from pre-sorted evidence and never
cross lenses. Fill it top to bottom; do not skip ahead to the verdicts.
