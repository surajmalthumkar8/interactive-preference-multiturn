🛠️ Production Ops


Welcome to the production phase of Interactive Preference | Multi-Turn!


* This page provides an overview of the production workflow and points you to the resources you need to complete tasks successfully. For detailed project requirements, always refer to the current Project Guidelines.


✅ Before you start

Production access is provided only after you have been determined eligible through the project screening process.
Once you are eligible, you will receive the required permissions and credentials and be added to the relevant production tools.
Before claiming your first task, make sure you can access:

* Vercel
* Feather
* Any other tools required for production

If you are missing access or your permissions do not appear to be correct, use Get Help to report the issue.

1. 🔐 Access & credentials

Your production work requires access to the project's designated tools.

Vercel

[Vercel link]
Use Vercel according to the project's current production workflow.

Feather

[Feather link]
Use Feather to access and claim available production tasks.
If you cannot access one of the required tools, do not create duplicate accounts or attempt to work around the permissions system. Report the issue through the appropriate support path.

2. 🎯 Claiming a task

Once you have production access:

1. Open the designated production platform.
2. Find an available task.
3. Review the task information before claiming it.
4. Claim the task according to the current project procedure.
5. Complete the task according to the project guidelines.

[Link to task-claiming instructions]
Only claim tasks that you are prepared and able to complete.

3. ✍️ Producing a conversation

The goal of each task is to produce a diverse, high-quality 10–15-turn conversation in which:

* the user develops prompts across the conversation;
* the interaction remains natural and coherent across turns;
* the model's responses are evaluated;
* one of two responses is selected as preferred;
* the preference is supported by appropriate reasoning.

Follow the current project guidelines for the detailed requirements and quality standards.
[Link to Project Guidelines]

4. ✏️ Editing your work

If you need to make changes to a task before submission, follow the current editing procedure.
[Link to editing instructions]
Do not assume that a task can be edited after submission. Follow the current platform and project instructions.

5. 📤 Submission

Before submitting:

* Review the conversation against the project guidelines.
* Make sure all required fields are complete.
* Check that the selected preference is correct.
* Make any necessary edits.
* Submit the task through the designated production workflow.

[Link to submission instructions]
Once submitted, your work enters the project's Quality Check process.

6. 🔎 Quality & compliance

Quality matters throughout the production process.
Your work is evaluated for adherence to the project's requirements and quality standards through the project's Quality Check (QC) mechanism.
There is no contributor-to-contributor review layer. Individual tasks are not assigned to another contributor for review, and contributors are not expected to review one another's work.
You are nevertheless responsible for reviewing your own work carefully before submission.

7. 🆘 Something isn't working?

I cannot access Vercel or Feather

Use Get Help → Operational Issue.

I cannot claim a task

Use Get Help → Operational Issue and provide the relevant task or platform details.

I cannot edit or submit a task

Use Get Help → Operational Issue and describe what happened.

I am unsure how to handle a project-specific task

This is a Project / Quality question, not an operational issue. Use Get Help → Project / Quality Question.

I have a platform-wide issue

For payments, global permissions, account issues, or other non-project-specific matters, use the general onboarding resources or #all-trainner-hub.

📌 Keep in mind
