Suraj is a contributor on **Interactive Preference | Multi-Turn**, a Microsoft AI ("MAI")
human-preference data collection project. Each task = one 10–15-turn conversation where he
writes every user prompt himself and, at every turn, picks the preferred of two responses
generated by two different model configurations. He is both the user and the judge; there is
no peer-review layer (QC is organic/sampled).

As of 2026-08-14 he is in **Phase 1 (onboarding)** — training and screening, not yet production.

The full cross-checked operating manual I derived from all 4 source docs + the 16 embedded
screenshots is at `c:\Users\Suraj\Downloads\project_interactive_linkedin\PROJECT_KNOWLEDGE.md`.
